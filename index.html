Set up the Rotate bookmark (once)
  1. Tap Copy bookmark code.
  2. In Safari, bookmark any page (Share › Add Bookmark).
  3. Edit that bookmark: name it Rotate and paste the code as its address.
  4. On CrewLink, open the bookmarks and tap Rotate.

The bookmark only works on crewlink.ita-airways.com. It downloads the duty plan you can already see there (this month, next month and, in the first week, last month) and copies it for Rotate. Your password is never read or stored and nothing is sent to other servers.
